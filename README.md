# Deception+

[![Tests](https://github.com/henrybednar/pitcher-deception-metric/actions/workflows/tests.yml/badge.svg)](https://github.com/henrybednar/pitcher-deception-metric/actions/workflows/tests.yml)

Deception+ is a pitcher metric built from scratch on Statcast pitch-level data for 2025 and 2026. It compares what happened on each pitch with what a model expects from the pitch's measured traits, the batter, the catcher, the count, the park, and pitcher-batter handedness. A pitcher's score is how far their results land above or below that expectation. 100 is the qualified-pitcher average and 10 points is one standard deviation, the same scale as Stuff+.

The gap between result and expectation is not proven to be deception. It is whatever the model does not explain. Pitch sequencing, tunneling, spin mirroring, tempo, and arm slot were each tested as explanations and none accounts for it. The score is also not independent of pitch quality: it correlates 0.40 with Stuff+ (see Decisions).

## Outputs

- `deception_dashboard.html` has the pitch-model validation, the charts, the validation table, the method, and an audit log of the leaks and bugs found along the way.
- `deception_leaderboard.html` is a sortable table of every scored pitcher-season with 95% intervals and a starter or reliever filter.

Open both from the same folder so their links work. Both pages are built from `templates/`, and every figure in their text comes from `site_stats.json`, so a pipeline rerun cannot leave them out of date.

## Run it

Python 3.11.

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run_pipeline.py
```

The pipeline starts from the raw files listed in `RAW_INPUTS` in `run_pipeline.py`. A full run takes about 23 minutes on a 24-thread machine and needs about 1.3 GB of free disk. `python run_pipeline.py --list` shows the steps, `--from STEP` and `--only STEP` run part of it, and each step logs to `logs/`.

`--pull` runs `data_pull.py` first. It fetches whatever Savant has that day, so the data cutoff and every downstream number move with it. Two more files are pasted from FanGraphs by hand because scripted access is blocked, neither used in scoring: `raw/fangraphs_stuff_manual.tsv` for the Stuff+ scatter and fifths chart on the dashboard and the leaderboard column, and `raw/fangraphs_standard_*.tsv` (games, games started, innings pitched) for a real games-started-share role label instead of a pitches-per-appearance proxy.

Raw pulled and manually-dropped files live in `raw/`; everything the pipeline generates (intermediates, reports, and the JSON the pages read) lives in `output/`. The two HTML pages and every `.py` script stay at the project root.

Tests: `pip install -r requirements-dev.txt`, then `pytest`.

## Pipeline

| Step | What it does |
|---|---|
| `merge_data` | Joins the raw files into pitcher-season covariate tables |
| `driver_features` | Season-level candidate explanations: tunnel differential, spin mirror, release consistency, tempo |
| `build_pitch_table` | Per-pitch features, targets and the half assignment |
| `fit_full_model` | Whiff, chase, ground ball and weak contact models: stuff, pitch physics, location, batter and catcher tendencies (built inside each fold), count, park, platoon, averaged over three random pitcher splits, then a month recalibration of each expectation |
| `fit_swing_alignment` | Timing, horizontal alignment and whiff miss distance against each hitter's ideal contact point |
| `fit_timing_direction` | Signed timing model on stuff and location only, on contact swings, a readout kept out of the score |
| `fit_called_strike` | Called strike model (tested, not scored) |
| `reliability_and_ci` | Shrinkage, component intervals, the composite and its interval, split-half reliability, player names and the FanGraphs Stuff+ columns |
| `add_timing_direction` | Signed timing readout with intervals |
| `driver_analysis` | What explains each residual, season level, with Benjamini-Hochberg adjusted p-values |
| `predictive_validity` | Does a 2025 score predict 2026? |
| `sequencing_driver_analysis` | Does the previous pitch explain the residual, pitch level |
| `pitch_surprise` | How unpredictable each pitch type was given the situation, and whether surprise predicts the residual |
| `stuffplus_relationship` | Average result by Stuff+ fifth within pitch type, and the Stuff+ slope for each pitch type alone and on first pitches only |
| `model_validation` | Out-of-fold AUC, log loss, calibration and R-squared for every pitch model |
| `export_data`, `build_pages` | JSON, text figures and the two HTML pages |

## Components

| Component | Measures | In Deception+ |
|---|---|---|
| Whiff | Swings that miss | Yes |
| Chase | Swings at pitches outside the zone | Yes |
| Ground ball | Ground balls among balls in play | No, shown as its own readout |
| Weak contact | Balls in play under 85 mph | Yes |
| Timing | Gap between contact depth and the hitter's ideal depth, early or late, on contact swings | Yes |
| Whiff miss distance | Ball-to-barrel distance on a miss, log scale | Yes |
| Called strike | Takes called strikes | No, dropped (validation table only) |
| Horizontal alignment | Gap between horizontal reach and the hitter's ideal, tied up or flail, on contact swings | No, validation table only |

Every component is an out-of-fold gradient-boosted residual per pitch type, shrunk toward 100 with empirical Bayes. Folds are grouped by pitcher, and batter and catcher tendencies leave out every pitch from the pitcher being scored. The composite weights members by league-wide split-half reliability and by the pitcher's sample size.

Bat-tracking components need each hitter's ideal contact point, which the pitch-level export does not include. `swing_alignment.py` estimates it from the hitter's hardest-hit balls after adjusting exit velocity for bat speed and pitch speed.

## Decisions

Statistics below were measured on 2025-26 data through September 27, 2026 (the completed 2026 regular season), after the fixes listed under "Fixes". The first bullet's reliability and year-over-year numbers are current as of the last fix. The others are comparisons against options not adopted (dropping a member, adding one back); they were measured at an earlier checkpoint and the composite's absolute numbers have moved slightly since, but nothing in the later rounds changed how these components relate to each other, so the comparisons and the decisions they support still hold.

- Deception+ has 5 members: whiff, chase, weak contact, timing and whiff miss distance. Composite reliability (split-half, Spearman-Brown corrected; the raw half-to-half r is 0.587) is 0.740 and year-over-year correlation is 0.602 across every scored pitcher (0.644 among the 359 qualified in both seasons, 95% interval 0.56 to 0.70; 0.75 for the higher-volume half and 0.46 for the lower).
- Timing measures distance from the hitter's ideal contact depth, early or late, on swings that made contact. Against Savant's on-time share it correlates -0.57. Previous-pitch features are in no model's expectation. Sequencing is the pitcher's choice, so it is tested as an explanation instead.
- Whiff miss distance is a member. Dropping it lowers reliability from 0.740 to 0.708 and year-over-year correlation from 0.602 to 0.576.
- Ground ball was taken out of the composite and is shown as its own readout. Its talent is nearly uncorrelated with the other members (index correlations of at most 0.20), and a pitcher's 2025 Deception+ correlates -0.02 with their 2026 ground-ball index, and so it is a separate skill. With it in, reliability is 0.712 and year-over-year correlation 0.572. Among qualified pitcher-seasons four moved by more than 10 points: Clayton Kershaw in 2025 (86 to 98), Tyler Rogers in 2025 (94 to 104) and 2026 (95 to 107), and Tim Hill in 2026 (93 to 104). Add `gb` to `COMPOSITE_OUTCOMES` in `reliability_and_ci.py` to reverse it.
- Horizontal alignment is modeled and tested but appears only in the dashboard's validation table. It fails the forecast gate (p = 0.12, R² gain -0.0001), its year-over-year correlation is 0.12, and adding it lowers composite reliability from 0.740 to 0.712 and year-over-year correlation from 0.602 to 0.568. The pitch-level reach measure is distance from the body, not Savant's barrel offset, and location explains about 78% of it.
- Called strike was dropped from the composite and from the metric views at the user's request, and the corrected numbers support that. It is stable within a season (reliability 0.46) but its year-over-year correlation is 0.15 and its forecast gain is +0.001 (p = 0.012, above the 0.01 gate), a gap that umpire, catcher or park effects would produce. Adding it back lowers composite reliability from 0.740 to 0.713 and year-over-year correlation from 0.602 to 0.571. Add `calledstrike` to `COMPOSITE_OUTCOMES` to reverse it.
- Reweighting and multivariate shrinkage were tested and not adopted. Fit on 2025 and scored on 2026, eigenvector weights changed year-over-year correlation by -0.014 [-0.058, +0.028], and multivariate shrinkage did not improve any component's forecast significantly. Dropping the sample-size term from the composite weights gave the same reliability and year-over-year correlation (0.745 and 0.580, tested before the model changes below), so the weights are unchanged.
- Deception+ correlates 0.409 with Stuff+ among qualified pitcher-seasons (pitcher-clustered 95% interval 0.34 to 0.48; 0.445 in 2025, 0.369 in 2026), and every composite member does too: whiff 0.29, chase 0.28, weak contact 0.19, timing 0.17, whiff miss 0.35. Stuff+ is never a model input. The score is described as results beyond what the pitch's measured traits predict, not as everything outside pitch quality, and the dashboard shows the relationship by Stuff+ fifth within pitch type (`stuffplus_relationship.py`). For whiff, fastballs show no relationship across the fifths while off-speed and breaking pitches climb from -2.2 to +3.1 points; chase rises for both groups.
- The pitch models are validated out of fold (`model_validation.py`, charted on the dashboard). AUC by pitch type: whiff 0.75 to 0.84, chase 0.81 to 0.89, weak contact 0.68 to 0.76, ground ball 0.62 to 0.68, called strike 0.98 to 0.99. Log loss against a constant guess of each pitch type's base rate: whiff 0.423 against 0.525, chase 0.413 against 0.603, weak contact 0.554 against 0.634, ground ball 0.628 against 0.665. R-squared by pitch type: timing 0.06 to 0.21, whiff miss distance 0.07 to 0.41, horizontal alignment 0.72 to 0.83. Calibration slopes (1.0 is calibrated) run 0.997 to 1.059 for the five composite members, 1.012 for called strike, 1.008 for alignment and 1.004 for ground ball. Averaging three splits left the slopes a little above 1 (slightly flat predictions) and fixed ground ball, whose single-split slope was 0.92. The weak fits (ground ball, timing, whiff miss) leave most of their outcomes unexplained, so reliability and the forecast test, not model fit, decide what enters the score.
- Four explanations for the Stuff+ correlation were tested, and three were ruled out. Tail compression: the recalibration slope of actual on predicted is 0.998 for whiff, 1.021 for chase, 0.975 for weak contact, 0.998 for timing and 0.995 for whiff miss, so the models are not shrinking their extremes. Repertoire quality: for whiff, +10 points of a pitch type's own Stuff+ goes with +0.83 points of residual, and +0.80 with the rest of the pitcher's Stuff+ held fixed (the rest of the repertoire adds +0.10, p = 0.51). Same-season leakage: Stuff+ from the other season predicts the residual at 0.68 to 0.86 of the same-season slope, around Stuff+'s own year-to-year correlation of 0.81, so the relationship follows a stable property of the pitch. The fourth, fastball gaps, explains part of it (next bullet).
- Deception+ has its own 95% interval, which it did not before (only the components did). It combines each component's posterior variance with the composite weights and treats the components' errors as independent. A game bootstrap that resampled the same games for every component, run on 248 qualified pitcher-seasons, gave a standard deviation of the unshrunk composite 1.03 times the analytic one at the median (10th to 90th percentile 0.83 to 1.23), so the independence assumption holds. The leaderboard marks a score with a hollow circle when its interval includes 100, and every component tooltip now shows its interval (only whiff and whiff miss did).
- The dashboard's driver chart draws only the traits that survive a Benjamini-Hochberg correction across the 14 tested per component, with standard errors clustered on pitcher (3 of 14 for whiff, 1 for chase, 3 for ground ball, 1 for weak contact, 3 for timing, 4 for whiff miss). With 14 tests per component a few raw p-values below 0.05 are expected by chance, and the old chart ranked all 14 by random-forest permutation importance, which is noise at a cross-validated R² of 0.01 to 0.02. Clustering matters because 956 pitchers sit behind the 1,490 rows for whiff and a pitcher's two seasons are strongly dependent (their whiff residuals correlate 0.49): with classical errors vertical-approach-angle consistency survived for whiff and timing (q 0.026 and 0.016), and clustered it sits on the threshold (q 0.061 for whiff, 0.047 for timing) and crossed 0.05 between reruns of the scoring model, so it is a lead and not a finding. Pace, velocity gap and repeat rate, where they survive, held under classical, heteroskedasticity-robust, clustered and pitcher-averaged versions in a robustness run made before the month recalibration. Velocity gap and repeat rate both survive for whiff, timing and whiff miss, which is why the dashboard keeps its note on why both can be positive. The report (`report.pdf`) uses the same clustered errors and tiers features as survives the correction, nominal only, and not distinguishable from zero.
- Date features were tested in the models and not adopted; a post-hoc month recalibration was adopted instead (see Fixes). Adding the game month or the day of the year left the four-seam whiff month gap almost where it was (standard deviation 0.54 to 0.51 percentage points for the month, 0.50 for the day) and gained at most 0.0005 held-out log loss.
- Weighting and membership were re-tested just before the month recalibration, which moved the baseline year-over-year r from 0.641 to 0.643 among qualified pitchers. Five weightings (shipped, equal, reliability only, inverse posterior variance, reliability over posterior variance) give year-over-year r of 0.628 to 0.644 among qualified pitchers, all inside one interval of about plus or minus 0.07. Adding ground ball, called strike or alignment changes it by -0.01 to -0.03 and dropping timing by +0.005, also inside the interval, so the exclusions rest on the forecast test and on what each component measures, not on the year-over-year difference. Weak contact (reliability 0.27, below the 0.3 the membership rule asks for, forecast p = 0.0065) is a member by the forecast gate and adds about +0.01 year-over-year.
- Pitch unpredictability does not explain the residual (`pitch_surprise.py`). For each pitcher-season a regularized model predicts the pitch type from the count, the batter's side, the previous two pitch types, how the previous pitch ended, the outs and the baserunners, cross-fitted by game; surprise is the negative log of the probability given to the pitch thrown. The situation tells a hitter little: surprise falls from 1.32 nats (usage alone) to 1.21, and 96% of pitcher-seasons gain at least something. Within a pitcher's own pitches of one type, a more surprising pitch does not do better: per +1 nat the whiff result changes +0.17 pp [-0.02, +0.35], weak contact +0.25 [-0.11, +0.61], timing +0.03 in [-0.005, +0.06] and whiff miss +0.006, while chase falls -0.43 pp [-0.61, -0.25] (about 0.2 pp per within-type SD at most). Across qualified pitcher-seasons, with Stuff+ and role controlled, pitchers who spread their usage more evenly score a little lower (-1.1 index points per SD [-1.9, -0.2]) and pitchers whose choices follow the situation more score a little higher (+0.7 [+0.1, +1.4]), the opposite of unpredictability paying. It measures pitch type only, not location or speed patterns, from about 1,000 pitches per pitcher-season.
- Sequencing is not what creates the Stuff+ link. One way to test it is to compare pitchers one pitch type at a time (everyone's four-seamer against everyone else's four-seamer), so a pitch type's result cannot mix in another pitch. `stuffplus_relationship.py` now reports, for every pitch type with a FanGraphs Stuff+ (sweepers have none) and every composite member, the change in actual-minus-expected result per +10 of that pitch type's own Stuff+, weighted by sample size with errors clustered on pitcher. Because a pitch type's result still carries the effect of the pitch before it, the same slopes are also run on the first pitch of each plate appearance only, which has no previous pitch. Pooled within pitch type, per +10 Stuff+: whiff +0.83 pp over all pitches and +0.77 on first pitches, chase +0.77 and +0.58, timing +0.06 and +0.03 in, whiff miss +0.04 and +0.06 log units. Weak contact is +0.53 against +0.20 with a first-pitch interval of -0.38 to +0.78, too noisy to say. First-pitch swings are a selected sample (hitters swing at 31.8% of first pitches against 47.7% of all pitches, and batter-season first-pitch swing rates spread with an SD of 8.2 points against 4.8), so the check was repeated with the mean batter first-pitch aggression of each sample as a control (a one-off diagnostic, not a pipeline step): no slope moved by more than 0.05 (whiff +0.77 to +0.77, chase +0.58 to +0.53), and the batters a pitch type faces are no more aggressive when its Stuff+ is higher (about +0.1 points per +10 Stuff+). Hitters do swing more at higher-Stuff+ pitches of the same type, +1.0 points per +10 on first pitches and +1.1 on all pitches, equally in both samples, so that selection can add to the whiff-per-swing link in both but cannot explain why they match. By type, the whiff slope is +1.2 to +1.8 pp for cutters, changeups, curves, splitters and sliders (+1.4 for the 56 knuckle-curve samples) and flat for four-seamers (-0.11) and sinkers (0.00), so the earlier four-seamer-only look would have hidden it. Chase rises in every type, fastballs included (+0.51 for four-seamers). What a per-type test cannot separate is a pitch's own sequencing from its design relative to the pitcher's fastball, which is part of how FanGraphs rates secondaries; the earlier fastball-gap test is the evidence on that.
- Fastball-gap features were tested and not adopted. FanGraphs judges secondary pitches partly by their velocity and movement gaps to the pitcher's primary fastball, which the model does not see. Adding each pitch's velocity, vertical break, horizontal break and total movement gap to the pitcher's primary fastball (the more used of four-seamer and sinker, from tracking data only) raised held-out whiff AUC by 0.0017 to 0.0052 in five of eight pitch-type models (all five folds positive) and by at most 0.0009 for chase, and cut the off-speed and breaking whiff relationship with Stuff+ from +1.56 to +1.01 points per 10 Stuff+ points. In the full pipeline it lowered the correlation with Stuff+ from 0.399 to 0.336, but also lowered split-half reliability from 0.740 to 0.700, year-over-year correlation from 0.598 to 0.563 and the composite forecast delta R-squared from +0.050 to +0.038, and weak contact would fail its forecast gate (p = 0.052). The signal the features moved into the expectation was repeatable, so lowering the correlation cost the score's stability and the features stayed out.

## Fixes

- Pitches with no model prediction (unclassified pitch types, knuckleballs, eephus, position players, about 1.4%) were counted in each pitcher's sample and actual total but not in the expected total. That biased residuals and depressed reliability: whiff 0.664 to 0.679, chase 0.293 to 0.599, called strike 0.210 to 0.651. Only pitches with a prediction are counted now.
- Timing was scored on all swings, and on a whiff the bat-ball intercept is a closest-approach point that sits far from the ideal (14.0 in against 7.3 on contact). Timing correlated 0.39 with whiff rate. On contact swings that is 0.04, and the whiff-timing index correlation fell from 0.49 to 0.22.
- Batter and catcher tendencies were built once over all data, so training rows carried outcomes from held-out pitchers (out-of-fold AUC 0.010 too high in a whiff test on four-seamers). They are now built inside each fold from training pitchers.
- One infinite value in a fitted column would have poisoned every timing score. Non-finite values and impossible tracking reads are cleared before any feature is built, about 140 of 1.4 million rows. Balls in play with no exit velocity (about 1%) were counted as not weak contact and are now excluded.
- The scale was not centered: qualified Deception+ averaged 102.1. Shrinkage now targets the grand mean and Deception+ is centered on the qualified population.
- Intervals are the wider of the game-cluster bootstrap and an analytic posterior interval. A saturated sample (30 whiffs out of 30) used to get a zero-width interval and pitcher-seasons under 3 games got none.
- The sampling-variance floor of 1e-9 gave pitcher-seasons with a predicted rate of exactly 0 or 1 a weight near a billion in the between-pitcher variance estimate. Each pitch's Bernoulli variance is now taken with its predicted rate clipped to 0.01-0.99.
- Binary sampling variance used the pitcher-season's average predicted rate, p(1-p)/n, as if every pitch had that rate. The pitch-level sum of p(1-p) is smaller when predictions vary, and the pooled formula overstated it by about 1.3 times for whiff, 1.5 times for chase, 1.2 times for weak contact and 4.8 times for called strike. That pinned called strike's between-pitcher variance at its floor and collapsed its index (year-over-year 0.02, now 0.11). Variance is now summed pitch by pitch.
- The design effect was a median of per-pitcher ratios floored at 1, so it read 1.00 for every binary outcome. Short samples bias that median low, and the pooled variance was too large besides. It is now a game-weighted ratio with the bootstrap's (g-1)/g bias undone, and runs from 1.01 to 1.16 (whiff 1.14).
- The DerSimonian-Laird between-pitcher variance was driven by a few extreme pitcher-seasons: on whiff, 21 had standardized misses beyond 4, and in a stress test five saturated 30-pitch samples raised the estimate 16-fold. It is now a Paule-Mandel estimate with standardized misses capped at 4 (`estimate_true_var`). Component indexes for the composite members moved by under 1 point on average and Deception+ by 0.33 points (rank correlation 0.999, top-25 overlap 24 of 25).
- Pitches missing a core tracking value (spin, extension, effective speed, movement, approach angles, release point or plate location) are left out of scoring, about 0.3% of pitches. The missingness is informative: swings with no effective speed whiff 10% of the time against 23% for the rest, and a tree model sends a rarely seen missing value down an arbitrary branch. Pitches whose value a range check had cleared got expected whiff rates off by up to 13 points. Arm angle is exempt, since it is missing on 2% of pitches and the model learns from that.
- Zone bounds now have range checks, and a plate height with a zero, negative or missing zone gets NaN. None occur in the current data.
- Actual minus expected drifted by month: whiff ran from -0.3 to +1.3 percentage points between months, chase -0.4 to +1.3, weak contact -1.1 to +1.0 and ground ball -0.9 to +3.1, and the 2025 and 2026 averages for whiff, chase and whiff miss sat 2 to 3 index points apart even with season as a feature. No feature could see the date, so a pitcher who threw mostly in one stretch inherited it: for the four binary outcomes the month alone moved a qualified pitcher by 2 to 3.5 index points (standard deviation) and by 3 to 6 at the 95th percentile. `recalibrate_oof_by_group` (`fit_full_model.py`) now shifts each expectation by the league-wide gap of its year and month, estimated from other pitchers only (grouped by pitcher, so a pitcher never sets their own offset), for every scored outcome and the validation-only alignment outcome. The month gap falls to 0.004 percentage points (whiff), implied pitcher bias to under 0.1 index points, and the season gap disappears. Held-out log loss moved by at most 0.0003 (chase 0.4157 to 0.4159), qualified Deception+ moved 0.5 points on average (largest 1.9, correlation 0.998, top 25 unchanged), composite reliability 0.740 to 0.741 and year-over-year 0.598 to 0.603. Called strike is left out: its month gap is small (0.24 percentage points) and the step cost log loss (0.1295 to 0.1300).
- A pitcher's expectation depends on which other pitchers share their cross-validation fold. Two random pitcher-to-fold assignments gave component indexes that differed by an SD of 2.5 to 3.0 index points (correlation 0.96 to 0.97, largest gaps 12 to 32), so one run carries about 2 points per component. It surfaced when removing 0.5% of pitches (next bullet) moved qualified Deception+ by 1.2 points on average, up to 14, by reshuffling the folds. The noise is shared by both seasons of a pitcher and both halves of a season, so reliability and year-over-year stability cannot see it and the intervals do not include it. `FOLD_SEEDS` in `fit_full_model.py` now averages the out-of-fold predictions of three random grouped splits for the scored outcomes, which cut the whiff index difference between two runs from 2.8 to 1.6 points (correlation 0.969 to 0.990) at three times the fitting time. About 1 point per component remains. Called strike and the signed timing readout keep one split.
- Hit-by-pitch, bunt attempts and pitchouts are left out of scoring (`blank_noncompetitive_pitches`): a hit batter counted as a pitch the hitter chose not to swing at, and a bunt attempt counted as a swing. Season-level driver features, pitch counts, pitch-mix entropy, the sequencing aggregates and the leaderboard role proxy now use regular-season pitches only, like the scores (spring training and the postseason were 5.8% of 2025 pitches). Bunts put in play cannot be identified from the columns pulled and stay in.
- The signed timing readout (leaderboard Timing dir) was fit on every swing, including whiffs, where the intercept is a closest-approach point, the reason the scored timing component uses contact swings only. It correlated 0.29 with the whiff index, 0.43 with whiff miss distance and 0.36 with chase. It now uses contact swings, like the component. The correlations fell only to 0.26, 0.35 and 0.32, so most of that relationship is not whiff leakage: pitchers who miss more bats also tend to get earlier contact on the swings that do connect.
- Stuff+ and the games, starts and innings export are matched to Statcast by normalized name, and three names belong to two pitchers each (Luis García, Jacob Webb, Yunior Marte), so a plain name lookup silently kept the last one: the HOU García had no Stuff+ and his games, starts and innings were added to the other García's, the SF Yunior Marte had none and the CIN one carried his 85. Shared names are now resolved by the team on the FanGraphs row against the teams each pitcher threw for that season (`resolve_fangraphs_pitchers` in `merge_data.py`, with `FANGRAPHS_TEAM_TO_STATCAST` for the abbreviations that differ), and a row that still cannot be told apart is left unmatched instead of guessed. Four pitcher-seasons changed, none of them a qualified Stuff+ value (the qualified García keeps 109, with 58 games and 0 starts instead of 60 and 2), so no published correlation moved.
- Timing's model no longer controls for the previous pitch, which no other component's did. Sequencing is the pitcher's choice, so `sequencing_driver_analysis.py` tests it as an explanation, now with the shared pair features including tunnel separation (R² at most 0.002). In isolation the control was worth 0.37% of squared error.
- Knuckle curves (about 3,500 rows for ground ball, weak contact and whiff miss) had a model with no skill: log loss 0.694 against 0.693 for a constant. They now share the curveball model with pitch type as a feature. That improves knuckle-curve log loss by 0.025 (ground ball) and 0.034 (weak contact) and squared error by 0.063 (whiff miss), and helps curveballs slightly.
- Pitch physics features (late break, drag, extension gain, share of flight time at the decision point; `physics_features.py`) join the stuff features. On four-seamers they lowered whiff log loss by 0.0005 (interval 0.0002 to 0.0008) and timing squared error by 0.11%.
- The index divisor is a winsorized standard deviation, so a few extreme pitcher-seasons cannot stretch the scale (five saturated samples tripled the plain SD in a stress test; in real data the plain SD is inflated by less than 2%). A component whose pitcher-seasons do not differ by more than sampling noise (Cochran's Q, p above 0.05) scores 100 for everyone. Before, a component with no talent still got an index spread of 10 in 47% of 300 simulated cases.
- Tested and left alone: raising the iteration cap from 300 to 800 (whiff log loss +0.00005 with an interval that includes zero, weak contact and timing unchanged) and dropping the sample-size term from the composite weights.
- Net effect of this round on the composite (measured before the September 27 re-pull below): split-half reliability 0.745 to 0.756 and year-over-year correlation 0.580 to 0.613. Deception+ rank correlation with the previous run was 0.977, top-25 overlap 21 of 25, and 51 qualified pitcher-seasons moved by more than 4 points.

- Re-pulling after the 2026 season ended (cutoff moved from September 12 to September 27) added about 4% more pitches and moved composite reliability from 0.756 to 0.749 and year-over-year correlation from 0.613 to 0.594. Deception+ rank correlation with the run just before this pull is 0.976, top-25 overlap 21 of 25. `pybaseball`'s own cache keys on each call's arguments, not on when it ran, so a re-pull with an unchanged date range silently returned the prior pull's stale result until `data_pull.py` was changed to clear the cache directory first.
- `game_type` is now checked at ingestion and postseason and spring-training pitches are dropped (postseason was 2.9-3.9% of 2025, spring training up to 3.9%). That removed 46,090 rows (3.1%) and 199 pitcher-seasons whose entire sample was non-regular-season, mostly low-workload rookies.
- Season is now a feature in every full-tier model. Without a way to see which year a pitch came from, the model read the leaguewide gap between 2025 and 2026 as pitcher skill: whiff residual ran +1.16 points in 2025 and -0.83 in 2026 before this change, +0.44 and -0.06 after.
- `l2_regularization` moved from 1.0 to 3.0 after a hyperparameter sweep on held-out pitchers found it beats the old value by 2.66e-4 log loss with a 95% interval entirely above zero. The population-level effect on Deception+ is a wash.
- Timing under-predicted actual deviation by 0.24 inches at the low end of its predicted range (the other nine deciles were within 0.08 inches). A post-hoc, out-of-fold isotonic recalibration fixed it: the worst-decile residual is now 0.02 inches, and the calibration gap across the whole predicted range is -0.0155 to +0.0207 inches, down from -0.075 to +0.192.
- Between-pitcher variance (tau2) was estimated from every pitcher-season row, so a pitcher with data in both 2025 and 2026 counted their own talent twice. About 650 pitchers have both seasons. Collapsing each pitcher to one n-weighted point before tau2 is estimated dropped it by about 9% for both whiff and timing.
- Net effect of this round (`game_type` filter, season as a feature, `l2_regularization=3.0`, timing recalibration, and the tau2 fix, measured together against the last checkpoint above): composite split-half reliability held at 0.749 and year-over-year correlation rose from 0.594 to 0.606.
- `spin_axis_gap` (`physics_features.py`) joins the stuff features: circular hours between the measured spin axis and the axis implied by observed movement, a seam-shifted-wake proxy for aerodynamic break a hitter's eye doesn't expect from the spin it reads. A held-out-pitcher test across all 5 folds found +0.0011 whiff AUC on four-seamers (95% interval +0.0004 to +0.0018, every fold positive) and no effect on timing (interval includes zero). Composite split-half reliability moved from 0.749 to 0.751 and year-over-year correlation from 0.606 to 0.609.
- `pitch_count_in_appearance` (`build_pitch_table.py`) joins the context features: this pitch's count within the outing, so the model can tell a reliever's 8th pitch of the night from a starter's 88th. Before it existed, qualified relievers averaged 102.8 against 96.8 for starters in actual-minus-expected whiff rate; a held-out test found most of that gap (about a 1.3-point residual, shrunk to about 0.1) was fatigue, not a real deception difference, with a small held-out AUC gain (+0.0004, 95% interval +0.0000 to +0.0007). A second FanGraphs export (games, games starts, innings pitched; `merge_fangraphs_standard` in `merge_data.py`) replaced the pitches-per-appearance role proxy with a real games-started share, which disagreed with the proxy on 17.7% of pitcher-seasons (mostly swingmen and spot starters), and the fatigue result held up the same way under either role source. After both changes, qualified relievers average 101.5 against 98.8 for starters, composite split-half reliability moved from 0.751 to 0.742 and year-over-year correlation from 0.609 to 0.604. Reliability is expected to drop a little here, since some of what looked like consistent pitcher skill was the same pitchers consistently throwing on a fresh arm.
- Two of the physics features (`tunnel_frac`, `ext_x_decel`) never carried their own weight: permutation importance was near-zero or negative across all 8 scored outcomes, and `tunnel_frac` correlates 1.000 with `decel_frac` (pure redundancy). A held-out test confirmed dropping both changes nothing (whiff AUC delta +0.0003, 95% interval -0.0003 to +0.0009; timing R² delta -0.0000, interval -0.0003 to +0.0003). A broader test that also dropped `decel_frac`, `ext_gain`, `release_extension` and `p_throws` found a small real cost to whiff (-0.0007 AUC, interval entirely below zero), so only the two confirmed-dead features were removed. Composite split-half reliability moved from 0.742 to 0.743 and year-over-year correlation from 0.604 to 0.600.
- Three context gaps identified in a control-variable audit, each tested before adopting. `times_faced_this_game` (`build_pitch_table.py`, the pitch-level version of times through the order: this at-bat's rank among the same pitcher-batter pair's meetings today) plus `outs`, `runners_on`, and `score_diff` (the pitching team's lead or deficit) together showed no harm on either outcome tested and a real gain for chase (+0.0002 AUC, 95% interval +0.0001 to +0.0004); whiff's own gain was in the same direction but not significant (interval included zero). A same-handed-specific batter tendency (`batter_tendency_same_hand`, alongside the existing blended `batter_tendency`, not replacing it) found a real gain for whiff (+0.0008 AUC, interval +0.0003 to +0.0013) and was neutral for chase. Composite split-half reliability moved from 0.743 to 0.740 and year-over-year correlation from 0.600 to 0.598, an expected small drop for features that add situational and platoon-specific context rather than raw between-pitcher consistency. Umpire identity, the fourth gap from that audit, turned out to have a workaround: Statcast's own `umpire` column ships empty, but MLB's public Stats API returns each game's home-plate umpire by game_pk (confirmed live, matched for all 4,859 regular-season games in this pull). An `umpire_tendency` feature (the umpire's own called-strike rate on other pitchers' takes that season, same fold-honest mechanism as batter and catcher tendency) was built and tested on called strike, the one outcome with a plausible umpire confound. A held-out test on four-seamers found no real gain (mean AUC delta +0.0000, 95% interval -0.0000 to +0.0001, not every fold positive): called strike's baseline AUC is already 0.988, almost entirely from plate location, leaving little room for umpire identity to register. Not adopted.

Numbers from before these fixes are not comparable.

## Reproducibility

- Before the fixes above, a clean rebuild from the raw files matched the previous outputs exactly on every column of `pitcher_season.csv`, `per_pitch_predictions.csv` and the report files.
- The full pipeline has been run from the raw files well over a dozen times as it changed, several from a fresh pull. A run takes about 10 to 13 minutes. Removing the unused model tiers and covariates reproduced the previous outputs to machine precision, and every later change moved the numbers exactly as described under Fixes, with no surprises on rerun.
- The bootstrap seed does not matter. On an earlier composite, five seeds gave the same reliability to three decimals, identical top-25 membership, and no Deception+ score moved by more than 0.12 points.
- Model seeds are fixed at 42.
- `pytest` runs 167 unit tests covering the swing-alignment reference, input hygiene, previous-pitch features, pitch physics (including the spin-axis-gap geometry), the in-game pitch count, times through the order, and the real-vs-proxy role label, fold-honest tendencies including the same-handed split, the season filter and season-as-a-feature (including that it absorbs a population-level calibration gap, not just a single held-out row), pitch-level variance, the between-pitcher variance estimator and its repeated-pitcher collapse, the design effect, shrinkage, the timing recalibration, the index scale, the composite weights, intervals, the row-alignment check, the model-fitting loop, the Stuff+ fifths summary, per-pitch-type slopes, first-pitch flags, the pitch-surprise measures and correlations, the model-validation metrics, the driver significance correction (including the pitcher-clustered version), the month recalibration and year-month label, the contact-swing mask, the Stuff+ name crosswalk, the repeated-split averaging, the forecast test, the stability and handedness statistics, the composite interval, and the site-stat helpers (p-value formatting, unscored share, ground-ball forecast correlation).

## Known limits

- Deception+ correlates 0.40 with Stuff+. Part of that is information Stuff+ has and the model lacks (fastball gaps for off-speed and breaking pitches), and part looks like repeatable signal. The score is not independent of pitch quality, and forcing it to be would cost reliability and forecast power.
- In-game fatigue (pitch count within the outing) and times through the order are both features now, and fatigue closed most of the reliever-vs-starter gap, but a smaller gap remains: qualified relievers average 101.4 against 98.9 for starters.
- Two completed regular seasons (2025 and 2026). A season fixed effect absorbs the level shift between them, but two seasons isn't enough to say whether deception talent trends over time.
- Vertical swing alignment (over or under) is not in the pitch-level export, and bat speed, swing length and attack angle are not scored.
- Weak contact is the noisiest member, with reliability near 0.27. The median 95% interval on Deception+ is about 13 points either side of the score, so only 200 of 1,031 qualified scores (19%) have an interval that excludes 100. The leaderboard marks the rest with a hollow circle.
- About 1.5% of pitches are not scored: unclassified pitch types, knuckleballs, eephus and other pitch types that share no model, pitcher-seasons averaging under 75 mph, hit-by-pitches, bunt attempts and pitchouts, and pitches missing core tracking values.
- Batter and catcher tendencies are built from each opponent's whole season, not a date-ordered window up to that point. That's the right choice for a retrospective season-level opponent-quality adjustment, but it means a pitch thrown in April can be informed by that batter's September performance too. It would need reworking before this metric could be used for real-time, in-season prediction.
- Many individually well-evidenced changes have gone into this metric over several audit rounds (season fixed effect, `l2_regularization`, `spin_axis_gap`, `pitch_count_in_appearance`, the tau2 collapse, timing recalibration, two rounds of dead-feature removal), each cleared on its own held-out interval. No formal correction (Bonferroni, FDR) has been applied across that whole sequence of decisions, so the true joint error rate is higher than any single change's reported interval suggests. The 2025-to-2026 forecast test is a genuinely independent check on this, and it's stayed positive and stable across every round, but that's a partial mitigation, not a resolution.
