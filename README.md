# Deception+

[![Tests](https://github.com/henrybednar/pitcher-deception-metric/actions/workflows/tests.yml/badge.svg)](https://github.com/henrybednar/pitcher-deception-metric/actions/workflows/tests.yml)

Deception+ is a pitcher metric built from scratch on Statcast pitch-level data for 2024, 2025 and 2026. It compares what happened on each pitch with what a model expects from the pitch's measured traits, the batter, the catcher, the count, the park, and pitcher-batter handedness. A pitcher's score is how far their results land above or below that expectation. 100 is the qualified-pitcher average and 10 points is one standard deviation, the same scale as Stuff+.

The gap between result and expectation is not proven to be deception. It is whatever the model does not explain. Pitch sequencing, tunneling, spin mirroring, tempo, and arm slot were each tested as explanations and none accounts for it. The score is also not independent of pitch quality: it correlates 0.37 with Stuff+ (see Decisions).

## Outputs

- `deception_dashboard.html` has the pitch-model validation, the charts, the validation table, the method, and an audit log of the leaks and bugs found along the way.
- `deception_leaderboard.html` is a sortable table of every scored pitcher-season with 95% intervals and a starter or reliever filter.

Open both from the same folder so their links work. Both pages are built from `templates/`, and every figure in their text comes from `site_stats.json`, so a pipeline rerun cannot leave them out of date.

## Run it

Python 3.11.

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run_pipeline.py
```

Downloading data (`--pull`) also needs `.venv\Scripts\pip install -r requirements-pull.txt`; nothing else does.

The pipeline starts from the raw files listed in `RAW_INPUTS` in `run_pipeline.py`. A full run takes about 77 minutes on a 24-thread machine and needs about 2 GB of free disk. `python run_pipeline.py --list` shows the steps, `--from STEP` and `--only STEP` run part of it, and each step logs to `logs/`.

`--pull` runs `data_pull.py` first (`python data_pull.py --years 2024` pulls one season and keeps the others' rows from the files already in `raw/`). It fetches whatever Savant has that day, so the data cutoff and every downstream number move with it. Two more files are pasted from FanGraphs by hand because scripted access is blocked, neither used in scoring: `raw/fangraphs_stuff_manual.tsv` for the Stuff+ scatter and fifths chart on the dashboard and the leaderboard column, and `raw/fangraphs_standard_*.tsv` (games, games started, innings pitched) for a real games-started-share role label instead of a pitches-per-appearance proxy.

Raw pulled and manually-dropped files live in `raw/`; everything the pipeline generates (intermediates, reports, and the JSON the pages read) lives in `output/`. The two HTML pages and every `.py` script stay at the project root.

Tests: `pip install -r requirements-dev.txt`, then `pytest`.

The driver report (`report.pdf`) is built after the pipeline: `python driver_ols_report.py`, then `python build_report.py` (every number and tier in `report.tex` comes from the outputs), then `pdflatex report.tex`.

## Pipeline

| Step | What it does |
|---|---|
| `merge_data` | Joins the raw files into pitcher-season covariate tables |
| `driver_features` | Season-level candidate explanations: tunnel differential, spin mirror, release consistency, tempo |
| `build_pitch_table` | Per-pitch features, targets and the half assignment |
| `fit_full_model` | Whiff, chase, ground ball and weak contact models: stuff, pitch physics, location, batter tendencies (overall, same-handed, by pitch type, by count, by zone) and catcher tendency (all built inside each fold), count, park, platoon, averaged over six random pitcher splits, then a month recalibration of each expectation |
| `fit_swing_alignment` | Timing, horizontal alignment and whiff miss distance against each hitter's ideal contact point |
| `fit_timing_direction` | Signed timing model on stuff and location only, on contact swings, a readout kept out of the score |
| `fit_called_strike` | Called strike model (tested, not scored) |
| `reliability_and_ci` | Shrinkage, component intervals, the composite and its interval, split-half reliability, player names and the FanGraphs Stuff+ columns |
| `add_timing_direction` | Signed timing readout with intervals |
| `driver_analysis` | What explains each residual, season level, with Benjamini-Hochberg adjusted p-values |
| `predictive_validity` | Does a season's score predict the next season's outcome rate? Every pair of consecutive seasons, stacked, with errors clustered on pitcher |
| `projection` | Projects each pitcher-season's Deception+ for the following season from this season and the one before it, with every projection out of sample and an 80% range |
| `outcome_validation` | Does Deception+ predict next-season strikeout rate, walk rate, xwOBA, wOBA and run value per 100 pitches beyond Stuff+, Location+ and last season's own result? Cross-validated R², the gain from Deception+ with an interval, the member coefficients, the stability of each metric and the timing demotion rule |
| `membership_check` | Rescores the composite with each member dropped and each candidate added, and compares year-over-year stability over every pair of consecutive seasons |
| `sequencing_driver_analysis` | Does the previous pitch explain the residual, pitch level |
| `pitch_surprise` | How unpredictable each pitch type was given the situation, and whether surprise predicts the residual |
| `stuffplus_relationship` | Average result by Stuff+ fifth within pitch type, and the Stuff+ slope for each pitch type alone and on first pitches only |
| `model_validation` | Out-of-fold AUC, log loss, calibration and R-squared for every pitch model |
| `export_data`, `build_pages` | JSON, text figures and the two HTML pages |

## Components

| Component | Measures | In Deception+ |
|---|---|---|
| Whiff | Swings that miss | Yes |
| Chase | Swings at pitches outside the zone | Yes |
| Ground ball | Ground balls among balls in play | No, shown as its own readout |
| Weak contact | Balls in play under 85 mph | Yes |
| Timing | Gap between contact depth and the hitter's ideal depth, early or late, on contact swings | Yes |
| Whiff miss distance | Ball-to-barrel distance on a miss, log scale | Yes |
| Called strike | Takes called strikes | No, dropped (validation table only) |
| Horizontal alignment | Gap between horizontal reach and the hitter's ideal, tied up or flail, on contact swings | No, validation table only |

Every component is an out-of-fold gradient-boosted residual per pitch type, shrunk toward 100 with empirical Bayes. Folds are grouped by pitcher, and batter and catcher tendencies leave out every pitch from the pitcher being scored. The composite weights members by league-wide split-half reliability and by the pitcher's sample size.

Bat-tracking components need each hitter's ideal contact point, which the pitch-level export does not include. `swing_alignment.py` estimates it from the hitter's hardest-hit balls after adjusting exit velocity for bat speed and pitch speed.

## Decisions

Statistics below were measured on 2024-26 data through September 27, 2026 (three completed regular seasons), after the fixes listed under "Fixes". The first bullet, the membership comparisons, the forecast test, the driver results, the validation figures, the Stuff+ slopes and the pitch-surprise results come from the three-season run. The Stuff+ diagnostics (tail compression, repertoire quality, same-season leakage), the fastball-gap test and the reweighting tests were one-off scripts measured on two seasons and earlier versions of the model and were not rerun; where a bullet says so, its figures predate the third season.

- Deception+ has 5 members: whiff, chase, weak contact, timing and whiff miss distance. Composite reliability (split-half, Spearman-Brown corrected; the raw half-to-half r is 0.590) is 0.740 and year-over-year correlation is 0.615 across every scored pair of consecutive seasons (1,089 pairs: 0.621 for 2024 to 2025 and 0.608 for 2025 to 2026), and 0.668 among the 704 pairs where the pitcher qualified in both seasons (95% interval 0.61 to 0.72, resampling pitchers; 0.74 for the higher-volume half and 0.55 for the lower).
- Timing measures distance from the hitter's ideal contact depth, early or late, on swings that made contact. Against Savant's on-time share it correlates -0.57. Previous-pitch features are in no model's expectation. Sequencing is the pitcher's choice, so it is tested as an explanation instead.
- Whiff miss distance is a member. Dropping it lowers reliability from 0.740 to 0.710 and year-over-year correlation from 0.615 to 0.573 (among qualified pairs by 0.050, interval -0.070 to -0.032).
- Ground ball was taken out of the composite and is shown as its own readout. Its talent is nearly uncorrelated with the other members (index correlations of at most 0.19), and a pitcher's Deception+ correlates -0.02 with their ground-ball index the next season, and so it is a separate skill. With it in, reliability is 0.709 and year-over-year correlation 0.593 (among qualified pairs lower by 0.027, interval -0.044 to -0.010). Among qualified pitcher-seasons two moved by more than 10 points: Clayton Kershaw in 2025 (87 to 98) and Tyler Rogers in 2026 (96 to 106). Add `gb` to `COMPOSITE_OUTCOMES` in `reliability_and_ci.py` to reverse it.
- Horizontal alignment is modeled and tested but appears only in the dashboard's validation table. It passes the forecast gate on three seasons only barely (p = 0.002, R² gain +0.0007, about 1% of a member's), its year-over-year correlation is 0.14, and adding it lowers composite reliability from 0.740 to 0.710 and year-over-year correlation from 0.615 to 0.584 (among qualified pairs by 0.029, interval -0.048 to -0.009). On the two seasons the gate was first set on, it failed (p = 0.09). The pitch-level reach measure is distance from the body, not Savant's barrel offset, and location explains about 78% of it.
- Called strike was dropped from the composite and from the metric views at the user's request, and the numbers support that. It is stable within a season (reliability 0.46) and its year-over-year correlation is 0.23, and on three seasons it passes the forecast gate (p < 0.0001), but with a gain of +0.004, a twentieth of timing's; on two seasons it did not (p = 0.02 on 2025 to 2026). A gap between within-season stability and carryover is what umpire, catcher or park effects would produce. Adding it back lowers composite reliability from 0.740 to 0.708 and year-over-year correlation from 0.615 to 0.575 (among qualified pairs by 0.033, interval -0.056 to -0.010). Add `calledstrike` to `COMPOSITE_OUTCOMES` to reverse it.
- Reweighting and multivariate shrinkage were tested and not adopted. Fit on 2025 and scored on 2026, eigenvector weights changed year-over-year correlation by -0.014 [-0.058, +0.028], and multivariate shrinkage did not improve any component's forecast significantly. Dropping the sample-size term from the composite weights gave the same reliability and year-over-year correlation (0.745 and 0.580, tested before the model changes below), so the weights are unchanged.
- Deception+ correlates 0.360 with Stuff+ among qualified pitcher-seasons (pitcher-clustered 95% interval 0.30 to 0.42; 0.290 in 2024, 0.429 in 2025, 0.360 in 2026), and every composite member does too: whiff 0.28, chase 0.20, weak contact 0.20, timing 0.13, whiff miss 0.34. Stuff+ is never a model input. The score is described as results beyond what the pitch's measured traits predict, not as everything outside pitch quality, and the dashboard shows the relationship by Stuff+ fifth within pitch type (`stuffplus_relationship.py`). For whiff, fastballs show no relationship across the fifths while off-speed and breaking pitches climb from -1.9 to +2.8 points; chase rises for both groups.
- The pitch models are validated out of fold (`model_validation.py`, charted on the dashboard). AUC by pitch type: whiff 0.76 to 0.85, chase 0.82 to 0.89, weak contact 0.66 to 0.76, ground ball 0.61 to 0.69, called strike 0.98 to 0.99. Log loss against a constant guess of each pitch type's base rate: whiff 0.420 against 0.526, chase 0.406 against 0.600, weak contact 0.552 against 0.635, ground ball 0.626 against 0.666. R-squared by pitch type: timing 0.07 to 0.23, whiff miss distance 0.10 to 0.40, horizontal alignment 0.74 to 0.84. Calibration slopes (1.0 is calibrated) run 0.998 to 1.076 for the five composite members, 1.029 for called strike, 1.012 for alignment and 1.015 for ground ball. Averaging splits leaves the slopes a little above 1 (slightly flat predictions), more so with six splits than with three (whiff 1.032 to 1.044, chase 1.059 to 1.076); it fixed ground ball, whose single-split slope was 0.92. The weak fits (ground ball, timing, whiff miss) leave most of their outcomes unexplained, so reliability and the forecast test, not model fit, decide what enters the score.
- Four explanations for the Stuff+ correlation were tested, and three were ruled out (the first three on two seasons and the model before the six-split round; the correlation they explain is 0.360 on three seasons, 0.410 on two). Tail compression: the recalibration slope of actual on predicted is 0.998 for whiff, 1.021 for chase, 0.975 for weak contact, 0.998 for timing and 0.995 for whiff miss, so the models are not shrinking their extremes. Repertoire quality: for whiff, +10 points of a pitch type's own Stuff+ goes with +0.83 points of residual, and +0.80 with the rest of the pitcher's Stuff+ held fixed (the rest of the repertoire adds +0.10, p = 0.51). Same-season leakage: Stuff+ from the other season predicts the residual at 0.68 to 0.86 of the same-season slope, around Stuff+'s own year-to-year correlation of 0.81, so the relationship follows a stable property of the pitch. The fourth, fastball gaps, explains part of it (next bullet).
- Deception+ has its own 95% interval, which it did not before (only the components did). It combines each component's posterior variance with the composite weights and treats the components' errors as independent. A game bootstrap that resampled the same games for every component, run on 248 qualified pitcher-seasons, gave a standard deviation of the unshrunk composite 1.03 times the analytic one at the median (10th to 90th percentile 0.83 to 1.23), so the independence assumption holds. The leaderboard marks a score with a hollow circle when its interval includes 100, and every component tooltip now shows its interval (only whiff and whiff miss did).
- The dashboard's driver chart draws only the traits that survive a Benjamini-Hochberg correction across the 14 tested per component, with standard errors clustered on pitcher (5 of 14 for whiff, 2 for chase, 3 for ground ball, 3 for weak contact, 3 for timing, 6 for whiff miss). With 14 tests per component a few raw p-values below 0.05 are expected by chance, and the old chart ranked all 14 by random-forest permutation importance, which is noise at a cross-validated R² of 0.01 to 0.02. Clustering matters because 1,104 pitchers sit behind the 2,224 rows for whiff and a pitcher's seasons are strongly dependent. Vertical-approach-angle consistency was a lead and not a finding on two seasons (clustered q 0.061 and 0.047, then 0.050 and 0.026 for whiff and timing across reruns of the scoring model, so it crossed 0.05 between reruns); on three seasons it survives with room (q 0.003 for whiff, 0.007 for timing), as does the spin-axis mirror score for whiff (q 0.006), both with the sign the tunneling idea predicts. Pace, velocity gap and repeat rate, where they survive, held under classical, heteroskedasticity-robust, clustered and pitcher-averaged versions in a robustness run made before the month recalibration. Velocity gap and repeat rate both survive for whiff, timing and whiff miss, which is why the dashboard keeps its note on why both can be positive. The report (`report.pdf`) uses the same clustered errors and tiers features as survives the correction, nominal only, and not distinguishable from zero.
- Date features were tested in the models and not adopted; a post-hoc month recalibration was adopted instead (see Fixes). Adding the game month or the day of the year left the four-seam whiff month gap almost where it was (standard deviation 0.54 to 0.51 percentage points for the month, 0.50 for the day) and gained at most 0.0005 held-out log loss.
- Weighting and membership were re-tested just before the month recalibration, which moved the baseline year-over-year r from 0.641 to 0.643 among qualified pitchers. Five weightings (shipped, equal, reliability only, inverse posterior variance, reliability over posterior variance) give year-over-year r of 0.628 to 0.644 among qualified pitchers, all inside one interval of about plus or minus 0.07. Adding ground ball, called strike or alignment changes it by -0.01 to -0.03 and dropping timing by +0.005, also inside the interval, so on those two seasons the exclusions rested on the forecast test and on what each component measures, not on the year-over-year difference. The three-season check below separates them. Weak contact (reliability 0.28, below the 0.3 the membership rule asks for, forecast p = 0.009) is a member by the forecast gate and adds about +0.01 year-over-year.
- Pitch unpredictability does not explain the residual (`pitch_surprise.py`). For each pitcher-season a regularized model predicts the pitch type from the count, the batter's side, the previous two pitch types, how the previous pitch ended, the outs and the baserunners, cross-fitted by game; surprise is the negative log of the probability given to the pitch thrown. The situation tells a hitter little: surprise falls from 1.30 nats (usage alone) to 1.19, and 96% of pitcher-seasons gain at least something. Within a pitcher's own pitches of one type, a more surprising pitch does not do consistently better: per +1 nat the whiff result changes +0.21 pp [+0.05, +0.36] (0.1 pp per within-type SD), weak contact +0.08 [-0.21, +0.37], timing +0.02 in [-0.005, +0.05] and whiff miss +0.013 log units [+0.004, +0.022], while chase falls -0.41 pp [-0.56, -0.27]. Across qualified pitcher-seasons, with Stuff+ and role controlled, pitchers who spread their usage more evenly score a little lower (-1.1 index points per SD [-1.9, -0.4]) and pitchers whose choices follow the situation more score a little higher (+0.9 [+0.3, +1.4]), the opposite of unpredictability paying. It measures pitch type only, not location or speed patterns, from about 1,000 pitches per pitcher-season.
- Sequencing is not what creates the Stuff+ link. One way to test it is to compare pitchers one pitch type at a time (everyone's four-seamer against everyone else's four-seamer), so a pitch type's result cannot mix in another pitch. `stuffplus_relationship.py` now reports, for every pitch type with a FanGraphs Stuff+ (sweepers have none) and every composite member, the change in actual-minus-expected result per +10 of that pitch type's own Stuff+, weighted by sample size with errors clustered on pitcher. Because a pitch type's result still carries the effect of the pitch before it, the same slopes are also run on the first pitch of each plate appearance only, which has no previous pitch. Pooled within pitch type, per +10 Stuff+: whiff +0.78 pp over all pitches and +0.78 on first pitches, chase +0.66 and +0.52, timing +0.05 and +0.01 in, whiff miss +0.04 and +0.05 log units. Weak contact is +0.59 against +0.17 with a first-pitch interval of -0.35 to +0.69, too noisy to say. First-pitch swings are a selected sample (hitters swing at 31.8% of first pitches against 47.7% of all pitches, and batter-season first-pitch swing rates spread with an SD of 8.2 points against 4.8), so the check was repeated with the mean batter first-pitch aggression of each sample as a control (a one-off diagnostic on the previous model, not a pipeline step): no slope moved by more than 0.05 (whiff +0.77 to +0.77, chase +0.58 to +0.53), and the batters a pitch type faces are no more aggressive when its Stuff+ is higher (about +0.1 points per +10 Stuff+). Hitters do swing more at higher-Stuff+ pitches of the same type, +1.0 points per +10 on first pitches and +1.1 on all pitches, equally in both samples, so that selection can add to the whiff-per-swing link in both but cannot explain why they match. By type, the whiff slope is +1.1 to +1.7 pp for cutters, changeups, curves, splitters and sliders (+1.1 for the 83 knuckle-curve samples) and flat for four-seamers (-0.02) and sinkers (+0.14), so the earlier four-seamer-only look would have hidden it. Chase rises in every type, fastballs included (+0.52 for four-seamers). What a per-type test cannot separate is a pitch's own sequencing from its design relative to the pitcher's fastball, which is part of how FanGraphs rates secondaries; the earlier fastball-gap test is the evidence on that.
- On-field validation (`outcome_validation.py`, the dashboard's "Does it matter on the field?" section). Across 671 pairs of consecutive seasons (452 pitchers, at least 150 batters faced in the second season), a pitcher's Deception+ predicts the next season's results beyond Stuff+ and Location+ for strikeout rate (cross-validated R² 0.233 to 0.304, gain +0.071 [+0.030, +0.109]) and xwOBA allowed (0.233 to 0.270, +0.037 [+0.013, +0.060]), and beyond last season's own result as well for xwOBA allowed (0.260 to 0.279, +0.019 [+0.003, +0.036]). Beyond last season's own strikeout rate the gain is +0.003 [-0.004, +0.010]. It adds nothing measurable for walk rate (-0.003) and little for wOBA allowed (+0.012 [-0.004, +0.027]) or run value per 100 pitches (+0.008 [-0.006, +0.022]). Deception+ is less stable year over year (0.70 among 579 qualified pairs) than the raw whiff rate it is built from (0.74), Stuff+ (0.79) and strikeout rate (0.68), as expected of a residual: its value is the part of results that stuff and location do not explain, not a better forecast of whiffs. By member, whiff and whiff miss distance carry strikeout rate, and whiff and weak contact carry xwOBA. Timing, the most reliable member, adds nothing measurable to either outcome (per SD -0.3 points of strikeout rate [-0.7, +0.1] and -0.8 points of xwOBA [-3.2, +1.6]). The rule written down for it: demote timing from the composite if, on both outcomes, the upper end of its interval is under 25% of whiff's effect. Strikeout rate meets that (ratio 0.11) and xwOBA does not (0.89, the interval is too wide to rule out a real effect), so timing stays in and the rule is checked on every run. These checks use 671 pairs, so a gain under about 0.01 R² cannot be told from zero.
- Next-season projection (`projection.py`, the leaderboard's Next season column). A score is one season of results, shrunk for its sample, so the best guess for next season sits closer to 100 and leans on the season before when there is one. Fit on every pair (one season) or triple (two seasons) of consecutive scored seasons: with one season next = 40.0 + 0.59 x this, with two next = 31.4 + 0.49 x this + 0.19 x previous. Each pitcher's projection comes from coefficients fit on other pitchers only (five random pitcher splits, averaged), so the backtest and the projection for the latest season are made the same way. Across the 1,089 projections that have an outcome the typical miss (RMSE) is 7.3 points, against 8.3 for using the season's score as the guess and 9.3 for guessing 100, and the 80% range, the projection plus or minus 1.28 times the out-of-sample error SD of its basis, covers 81% of outcomes. Most of the gain is shrinkage toward 100. The earlier season adds a little: on the 402 pitchers with two prior seasons the miss falls from 7.10 to 7.00 (+0.10 points, 95% interval -0.04 to +0.24), and that interval includes zero. Among the 340 of them who qualified, the gain is +0.13 [-0.02, +0.27]. Pitchers with only one scored prior season, including all rookies, are projected from that season alone. The projection says nothing about aging, injury or role changes.
- 2024 is a full scored season, and the membership decision holds on it. The decisions above were made on 2025 and 2026 alone. Before 2024 was added, the unmodified pipeline was run on 2024 and 2025 in a sandbox as an out-of-time check (a script that no longer exists, since 2024 is now part of the data): composite reliability 0.744, qualified-pair year-over-year 0.694, every member passing the forecast test, the same membership results and a Stuff+ correlation of 0.366. With 2024 in, the forecast test stacks both pairs of consecutive seasons and clusters on pitcher: every member passes, with cross-validated R² gains of whiff +0.065, chase +0.051, weak contact +0.018, timing +0.089 and whiff miss +0.052. Called strike (+0.004, p < 0.0001) and alignment (+0.0007, p = 0.002) pass the p < 0.01 gate too, with gains a fraction of a member's, so the gate alone no longer excludes them. `membership_check.py` (now a pipeline step) says why they stay out: among the 704 qualified pairs, adding ground ball lowers the composite's year-over-year correlation by 0.027 [-0.044, -0.010], called strike by 0.033 [-0.056, -0.010] and alignment by 0.029 [-0.048, -0.009], while dropping whiff miss costs 0.050 [-0.070, -0.032] and dropping whiff 0.056 [-0.081, -0.032]. Dropping chase costs 0.016 [-0.038, +0.007], weak contact 0.005 [-0.016, +0.004] and timing nothing (-0.001 [-0.029, +0.027], though reliability falls from 0.740 to 0.713), so those three stay on their forecast gains and their reliability. The exclusions now rest on three seasons of stability evidence. The same real 2025 season, scored by a run trained on 2024 and 2025 and by the main run, correlated 0.984 (SD of the difference 1.8 points), which is the score's sensitivity to the data its models are trained on.
- Fastball-gap features were tested and not adopted. FanGraphs judges secondary pitches partly by their velocity and movement gaps to the pitcher's primary fastball, which the model does not see. Adding each pitch's velocity, vertical break, horizontal break and total movement gap to the pitcher's primary fastball (the more used of four-seamer and sinker, from tracking data only) raised held-out whiff AUC by 0.0017 to 0.0052 in five of eight pitch-type models (all five folds positive) and by at most 0.0009 for chase, and cut the off-speed and breaking whiff relationship with Stuff+ from +1.56 to +1.01 points per 10 Stuff+ points. In the full pipeline it lowered the correlation with Stuff+ from 0.399 to 0.336, but also lowered split-half reliability from 0.740 to 0.700, year-over-year correlation from 0.598 to 0.563 and the composite forecast delta R-squared from +0.050 to +0.038, and weak contact would fail its forecast gate (p = 0.052). The signal the features moved into the expectation was repeatable, so lowering the correlation cost the score's stability and the features stayed out.

## Fixes

- 2024 added as a third scored season. `data_pull.py` pulls 2024 (`--years` keeps the other seasons' rows), the raw files are renamed `*_2024_2026.csv`, and the pitch file is about 1.5 GB. Bat tracking is complete from April 2024, so all five members are scored; 2023 has it only from August, so it is not used (FanGraphs Stuff+ and standard stats for 2023 to 2026 were already in `raw/`). Every statistic that paired 2025 with 2026 now pools every pair of consecutive seasons (`season_pairs.py`): year-over-year correlations, their intervals (resampling whole pitchers, since a pitcher's two pairs share a season), the ground-ball forecast correlation and the forecast test, whose p-value is now a test of the added term with errors clustered on pitcher and whose cross-validation folds are grouped by pitcher. The membership comparisons moved from one-off scripts into a pipeline step (`membership_check.py`) read by the page text, and the driver report is now generated by `build_report.py` instead of edited by hand (its tiers moved with the new data: vertical-approach-angle consistency and the spin-axis mirror score now clear the correction for whiff). `out_of_time.py` is removed. The count of scored pitcher-seasons went from 1,505 to 2,252 (qualified 1,031 to 1,542), composite reliability from 0.746 to 0.742, year-over-year correlation from 0.610 on one pair to 0.616 pooled over two, qualified-pair year-over-year from 0.653 to 0.671, and the Stuff+ correlation from 0.410 to 0.371 (0.304 in 2024). Relievers fill 17 of the top 25 qualified scores (13 before), and the left-handed gap is +1.3 points (p = 0.12 with errors clustered on pitcher; the test that treated every row as independent said 0.027, which a pitcher's repeated seasons made too small). A full run takes about 77 minutes, up from 53.
- Batter matchups and six-split averaging, from a performance audit. The full tier now also sees each batter's rate for the outcome against the same pitch type, in the same strike count and in or out of the zone (`TENDENCY_KEYS`, built inside each fold like the others), and `FOLD_SEEDS` averages six random pitcher splits instead of three. Held out by pitcher on one seed, the pitch-type tendency cut log loss by 0.0005 for whiff and 0.0020 for chase, the count tendency by 0.0015 for chase and the zone tendency by 0.0010 for whiff, each with an interval above zero. Their reverse pairings did nothing (the zone is constant across chase pitches, and the count added 0.0002 to whiff with an interval including zero), and a catcher-by-pitch-type tendency lost 0.0001 on chase and was left out. Six splits against three cut the whiff index difference between two runs with different seeds from 1.46 to 1.06 points and out-of-fold log loss by 0.0007; ten folds on three splits gave 1.28 and took as long as six splits. Year-over-year stability of the whiff index did not depend on any of it (0.51 to 0.52), because a pitcher's two seasons share a fold. Four-seam AUC rose from 0.753 to 0.759 for whiff and from 0.886 to 0.893 for chase. Scores barely moved: qualified Deception+ changed by 0.65 points on average (largest 3.1, correlation 0.997, top 25 overlap 24 of 25), each component by an SD of 1.1 to 1.3 points. Composite reliability went from 0.740 to 0.746 and year-over-year correlation from 0.602 to 0.610 (0.644 to 0.653 among qualified pairs). Called strike and the signed timing readout now average six splits too; called strike had kept one. A full run took about 53 minutes then, up from 23. Tested in the same audit and left alone: other composite weightings (equal, reliability only, sample size only, reliability squared, one-factor, and weights fit on the other season pair; none beat the shipped weights by more than 0.01 in year-over-year correlation on either pair, and equal or sample-size-only weights lost 0.02), the winsor clip (3 to 10) and the design effect (none, 1.5 times, 2 times), whose year-over-year changes were all under 0.01 and inside noise; an exit-velocity member in place of weak contact (reliability 0.37 against 0.27 on 2025 to 2026 and 0.33 against 0.24 on 2024 to 2025, but the composite's year-over-year moved +0.003 and -0.005); and ten folds in place of more splits. Shrinkage is calibrated: regressing next season's unshrunk results on this season's shrunk score gives similar slopes across sample-size terciles (composite 0.7 to 1.0, no trend with sample size). Adding a third training season is not adopted: out-of-fold whiff log loss improves by about 0.001 for each extra 12 to 20% of training data (0.4246 at 80% against 0.4236 at 90%), which puts a third season near 0.003.
- Pitches with no model prediction (unclassified pitch types, knuckleballs, eephus, position players, about 1.4%) were counted in each pitcher's sample and actual total but not in the expected total. That biased residuals and depressed reliability: whiff 0.664 to 0.679, chase 0.293 to 0.599, called strike 0.210 to 0.651. Only pitches with a prediction are counted now.
- Timing was scored on all swings, and on a whiff the bat-ball intercept is a closest-approach point that sits far from the ideal (14.0 in against 7.3 on contact). Timing correlated 0.39 with whiff rate. On contact swings that is 0.04, and the whiff-timing index correlation fell from 0.49 to 0.22.
- Batter and catcher tendencies were built once over all data, so training rows carried outcomes from held-out pitchers (out-of-fold AUC 0.010 too high in a whiff test on four-seamers). They are now built inside each fold from training pitchers.
- One infinite value in a fitted column would have poisoned every timing score. Non-finite values and impossible tracking reads are cleared before any feature is built, about 140 of 1.4 million rows. Balls in play with no exit velocity (about 1%) were counted as not weak contact and are now excluded.
- The scale was not centered: qualified Deception+ averaged 102.1. Shrinkage now targets the grand mean and Deception+ is centered on the qualified population.
- Intervals are the wider of the game-cluster bootstrap and an analytic posterior interval. A saturated sample (30 whiffs out of 30) used to get a zero-width interval and pitcher-seasons under 3 games got none.
- The sampling-variance floor of 1e-9 gave pitcher-seasons with a predicted rate of exactly 0 or 1 a weight near a billion in the between-pitcher variance estimate. Each pitch's Bernoulli variance is now taken with its predicted rate clipped to 0.01-0.99.
- Binary sampling variance used the pitcher-season's average predicted rate, p(1-p)/n, as if every pitch had that rate. The pitch-level sum of p(1-p) is smaller when predictions vary, and the pooled formula overstated it by about 1.3 times for whiff, 1.5 times for chase, 1.2 times for weak contact and 4.8 times for called strike. That pinned called strike's between-pitcher variance at its floor and collapsed its index (year-over-year 0.02, now 0.11). Variance is now summed pitch by pitch.
- The design effect was a median of per-pitcher ratios floored at 1, so it read 1.00 for every binary outcome. Short samples bias that median low, and the pooled variance was too large besides. It is now a game-weighted ratio with the bootstrap's (g-1)/g bias undone, and runs from 1.01 to 1.16 (whiff 1.14).
- The DerSimonian-Laird between-pitcher variance was driven by a few extreme pitcher-seasons: on whiff, 21 had standardized misses beyond 4, and in a stress test five saturated 30-pitch samples raised the estimate 16-fold. It is now a Paule-Mandel estimate with standardized misses capped at 4 (`estimate_true_var`). Component indexes for the composite members moved by under 1 point on average and Deception+ by 0.33 points (rank correlation 0.999, top-25 overlap 24 of 25).
- Pitches missing a core tracking value (spin, extension, effective speed, movement, approach angles, release point or plate location) are left out of scoring, about 0.3% of pitches. The missingness is informative: swings with no effective speed whiff 10% of the time against 23% for the rest, and a tree model sends a rarely seen missing value down an arbitrary branch. Pitches whose value a range check had cleared got expected whiff rates off by up to 13 points. Arm angle is exempt, since it is missing on 2% of pitches and the model learns from that.
- Zone bounds now have range checks, and a plate height with a zero, negative or missing zone gets NaN. None occur in the current data.
- Actual minus expected drifted by month: whiff ran from -0.3 to +1.3 percentage points between months, chase -0.4 to +1.3, weak contact -1.1 to +1.0 and ground ball -0.9 to +3.1, and the 2025 and 2026 averages for whiff, chase and whiff miss sat 2 to 3 index points apart even with season as a feature. No feature could see the date, so a pitcher who threw mostly in one stretch inherited it: for the four binary outcomes the month alone moved a qualified pitcher by 2 to 3.5 index points (standard deviation) and by 3 to 6 at the 95th percentile. `recalibrate_oof_by_group` (`fit_full_model.py`) now shifts each expectation by the league-wide gap of its year and month, estimated from other pitchers only (grouped by pitcher, so a pitcher never sets their own offset), for every scored outcome and the validation-only alignment outcome. The month gap falls to 0.004 percentage points (whiff), implied pitcher bias to under 0.1 index points, and the season gap disappears. Held-out log loss moved by at most 0.0003 (chase 0.4157 to 0.4159), qualified Deception+ moved 0.5 points on average (largest 1.9, correlation 0.998, top 25 unchanged), composite reliability 0.740 to 0.741 and year-over-year 0.598 to 0.603. Called strike is left out: its month gap is small (0.24 percentage points) and the step cost log loss (0.1295 to 0.1300).
- A pitcher's expectation depends on which other pitchers share their cross-validation fold. Two random pitcher-to-fold assignments gave component indexes that differed by an SD of 2.5 to 3.0 index points (correlation 0.96 to 0.97, largest gaps 12 to 32), so one run carries about 2 points per component. It surfaced when removing 0.5% of pitches (next bullet) moved qualified Deception+ by 1.2 points on average, up to 14, by reshuffling the folds. The noise is shared by both seasons of a pitcher and both halves of a season, so reliability and year-over-year stability cannot see it and the intervals do not include it. `FOLD_SEEDS` in `fit_full_model.py` was first set to average the out-of-fold predictions of three random grouped splits for the scored outcomes, which cut the whiff index difference between two runs from 2.8 to 1.6 points (correlation 0.969 to 0.990) at three times the fitting time. It is now six (first bullet of this list).
- Hit-by-pitch, bunt attempts and pitchouts are left out of scoring (`blank_noncompetitive_pitches`): a hit batter counted as a pitch the hitter chose not to swing at, and a bunt attempt counted as a swing. Season-level driver features, pitch counts, pitch-mix entropy, the sequencing aggregates and the leaderboard role proxy now use regular-season pitches only, like the scores (spring training and the postseason were 5.8% of 2025 pitches). Bunts put in play cannot be identified from the columns pulled and stay in.
- The signed timing readout (leaderboard Timing dir) was fit on every swing, including whiffs, where the intercept is a closest-approach point, the reason the scored timing component uses contact swings only. It correlated 0.29 with the whiff index, 0.43 with whiff miss distance and 0.36 with chase. It now uses contact swings, like the component. The correlations fell only to 0.26, 0.35 and 0.32, so most of that relationship is not whiff leakage: pitchers who miss more bats also tend to get earlier contact on the swings that do connect.
- Stuff+ and the games, starts and innings export are matched to Statcast by normalized name, and three names belong to two pitchers each (Luis García, Jacob Webb, Yunior Marte), so a plain name lookup silently kept the last one: the HOU García had no Stuff+ and his games, starts and innings were added to the other García's, the SF Yunior Marte had none and the CIN one carried his 85. Shared names are now resolved by the team on the FanGraphs row against the teams each pitcher threw for that season (`resolve_fangraphs_pitchers` in `merge_data.py`, with `FANGRAPHS_TEAM_TO_STATCAST` for the abbreviations that differ), and a row that still cannot be told apart is left unmatched instead of guessed. Four pitcher-seasons changed, none of them a qualified Stuff+ value (the qualified García keeps 109, with 58 games and 0 starts instead of 60 and 2), so no published correlation moved.
- Timing's model no longer controls for the previous pitch, which no other component's did. Sequencing is the pitcher's choice, so `sequencing_driver_analysis.py` tests it as an explanation, now with the shared pair features including tunnel separation (R² at most 0.002). In isolation the control was worth 0.37% of squared error.
- Knuckle curves (about 3,500 rows for ground ball, weak contact and whiff miss) had a model with no skill: log loss 0.694 against 0.693 for a constant. They now share the curveball model with pitch type as a feature. That improves knuckle-curve log loss by 0.025 (ground ball) and 0.034 (weak contact) and squared error by 0.063 (whiff miss), and helps curveballs slightly.
- Pitch physics features (late break, drag, extension gain, share of flight time at the decision point; `physics_features.py`) join the stuff features. On four-seamers they lowered whiff log loss by 0.0005 (interval 0.0002 to 0.0008) and timing squared error by 0.11%.
- The index divisor is a winsorized standard deviation, so a few extreme pitcher-seasons cannot stretch the scale (five saturated samples tripled the plain SD in a stress test; in real data the plain SD is inflated by less than 2%). A component whose pitcher-seasons do not differ by more than sampling noise (Cochran's Q, p above 0.05) scores 100 for everyone. Before, a component with no talent still got an index spread of 10 in 47% of 300 simulated cases.
- Tested and left alone: raising the iteration cap from 300 to 800 (whiff log loss +0.00005 with an interval that includes zero, weak contact and timing unchanged) and dropping the sample-size term from the composite weights.

Deception+ rank correlation with the previous run was 0.977, top-25 overlap 21 of 25, and 51 qualified pitcher-seasons moved by more than 4 points.

Deception+ rank correlation with the run just before this pull is 0.976, top-25 overlap 21 of 25. `pybaseball`'s own cache keys on each call's arguments, not on when it ran, so a re-pull with an unchanged date range silently returned the prior pull's stale result until `data_pull.py` was changed to clear the cache directory first.

A post-hoc, out-of-fold isotonic recalibration fixed it: the worst-decile residual is now 0.02 inches, and the calibration gap across the whole predicted range is -0.0155 to +0.0207 inches, down from -0.075 to +0.192.
- Between-pitcher variance (tau2) was estimated from every pitcher-season row, so a pitcher with data in both 2025 and 2026 counted their own talent twice. About 650 pitchers have both seasons. Collapsing each pitcher to one n-weighted point before tau2 is estimated dropped it by about 9% for both whiff and timing.

A held-out-pitcher test across all 5 folds found +0.0011 whiff AUC on four-seamers (95% interval +0.0004 to +0.0018, every fold positive) and no effect on timing (interval includes zero). Composite split-half reliability moved from 0.749 to 0.751 and year-over-year correlation from 0.606 to 0.609.
- `pitch_count_in_appearance` (`build_pitch_table.py`) joins the context features: this pitch's count within the outing, so the model can tell a reliever's 8th pitch of the night from a starter's 88th. Before it existed, qualified relievers averaged 102.8 against 96.8 for starters in actual-minus-expected whiff rate; a held-out test found most of that gap (about a 1.3-point residual, shrunk to about 0.1) was fatigue, not a real deception difference, with a small held-out AUC gain (+0.0004, 95% interval +0.0000 to +0.0007). ## Reproducibility

- Before the fixes above, a clean rebuild from the raw files matched the previous outputs exactly on every column of `pitcher_season.csv`, `per_pitch_predictions.csv` and the report files.
- The full pipeline has been run from the raw files well over a dozen times as it changed, several from a fresh pull. A run took 10 to 13 minutes then and takes about 77 now. Removing the unused model tiers and covariates reproduced the previous outputs to machine precision, and every later change moved the numbers exactly as described under Fixes, with no surprises on rerun.

## Known limits

- Deception+ correlates 0.37 with Stuff+ (0.30 in 2024, 0.44 in 2025, 0.37 in 2026). Part of that is information Stuff+ has and the model lacks (fastball gaps for off-speed and breaking pitches), and part looks like repeatable signal. The score is not independent of pitch quality, and forcing it to be would cost reliability and forecast power.
- In-game fatigue (pitch count within the outing) and times through the order are both features now, and fatigue closed most of the reliever-vs-starter gap, but a smaller gap remains: qualified relievers average 101.0 against 99.6 for starters.
- Three completed regular seasons (2024 to 2026). A season fixed effect absorbs the level shift between them, but two year-over-year pairs are still a short record for saying whether deception talent trends over time. 2023 is not scored: bat tracking starts in August 2023, so timing and whiff miss would cover about two months of it.
- Vertical swing alignment (over or under) is not in the pitch-level export, and bat speed, swing length and attack angle are not scored.
- Weak contact is the noisiest member, with reliability near 0.27. The median 95% interval on Deception+ is about 13 points either side of the score, so only 296 of 1,542 qualified scores (19%) have an interval that excludes 100. The leaderboard marks the rest with a hollow circle.
- About 1.5% of pitches are not scored: unclassified pitch types, knuckleballs, eephus and other pitch types that share no model, pitcher-seasons averaging under 75 mph, hit-by-pitches, bunt attempts and pitchouts, and pitches missing core tracking values.
- Batter and catcher tendencies are built from each opponent's whole season, not a date-ordered window up to that point. That's the right choice for a retrospective season-level opponent-quality adjustment, but it means a pitch thrown in April can be informed by that batter's September performance too. It would need reworking before this metric could be used for real-time, in-season prediction.
- Many individually well-evidenced changes have gone into this metric over several audit rounds (season fixed effect, `l2_regularization`, `spin_axis_gap`, `pitch_count_in_appearance`, the tau2 collapse, timing recalibration, two rounds of dead-feature removal), each cleared on its own held-out interval. No formal correction (Bonferroni, FDR) has been applied across that whole sequence of decisions, so the true joint error rate is higher than any single change's reported interval suggests. The year-ahead forecast test is a genuinely independent check on this, and it's stayed positive and stable across every round, but that's a partial mitigation, not a resolution.
